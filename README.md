Коллаборация — платформа для поиска команд на хакатоны
Веб-приложение, которое помогает разработчикам находить единомышленников, собирать команды для хакатонов и запускать совместные проекты.

## Проблема
Разработчикам сложно находить команду для хакатона: нет удобного инструмента, где можно указать свои навыки, посмотреть актуальные мероприятия и связаться с потенциальными тиммейтами.

## Функционал
- **Профили участников** — анкета с компетенциями, целями и контактами
- **Каталог мероприятий** — хакатоны, митапы и воркшопы с фильтрами по теме и формату
- **Свайп-механика** — быстрый поиск команды по анкетам (как в Tinder, но для разработчиков)
- **Командные чаты** — привязаны к конкретному мероприятию, без общего флуда
- **Страница партнёров** — информация о вузах и фондах поддержки

## Технологии
- HTML5, CSS3 (кастомные свойства, адаптивная вёрстка)
- Vanilla JavaScript
- Firebase (авторизация через Google, Firestore для хранения данных)
